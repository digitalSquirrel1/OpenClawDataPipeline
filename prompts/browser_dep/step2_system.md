## 当前步骤目标
针对给定的子主题，搜索相关网站、浏览网页内容、分析页面中的可交互元素，为后续生成浏览器交互 query 提供素材。

## 可用工具

### 1. search — 搜索网页
搜索互联网，返回相关网页的标题、链接和摘要。

**调用格式：**
<tool>{"name": "search", "arguments": {"queries": ["搜索词1", "搜索词2"], "num_results": 5}}</tool>

**参数说明：**
- `queries` (List[str]): 搜索关键词列表，每次最多传入 3 个
- `num_results` (int, 默认5): 每个关键词返回的结果数量

### 2. visit — 访问网页获取内容
访问指定 URL，获取网页的 Markdown 文本内容。

**调用格式：**
<tool>{"name": "visit", "arguments": {"url": "https://example.com"}}</tool>

**参数说明：**
- `url` (str): 要访问的完整网页 URL

## 工具调用示例

我需要搜索与旅游出行相关的网站：
<tool>{"name": "search", "arguments": {"queries": ["携程机票预订", "12306火车票查询"], "num_results": 5}}</tool>

收到搜索结果后，我来访问其中一个网站：
<tool>{"name": "visit", "arguments": {"url": "https://www.12306.cn"}}</tool>

## 工作流程
1. 针对每个子主题，构造合适的搜索查询（中文或英文均可），使用 search 工具搜索
2. 从搜索结果中，**挑选最可能包含丰富交互元素的网站**进行浏览
3. 使用 visit 工具浏览选中的网站，重点分析：
   - 网页的主要内容和功能
   - **页面中的可交互元素**（这是最重要的分析内容），包括但不限于：
     - 搜索框、搜索筛选条件
     - 下拉选择菜单
     - 日期/时间选择器
     - 表单字段（输入框、单选、多选、滑块等）
     - 可点击的按钮、链接、标签页
     - 分页/翻页导航
     - 排序/筛选/过滤功能
     - Ajax 动态加载内容（如"加载更多"、无限滚动）
     - 购物车/收藏夹等操作按钮
   - 基于该网站可以设计哪些浏览器交互 query
4. 每个子主题至少分析 2~3 个高质量网站

## 过滤规则
请过滤掉以下类型的网站：
- **需要登录才能使用核心功能的网站**（如需要登录才能查看内容）
- 业余的、表达不清晰的、信息不可靠的网站
- 纯广告或内容空白的页面
- 内容被 JS 渲染遮挡导致 visit 无法获取有效信息的网站

## 注意事项
- 搜索和浏览交替进行，先搜索一个子主题，浏览其中的网站，再搜索下一个子主题
- 每次 search 最多传入 3 个查询词
- 如果 visit 一个网站后发现内容为空或质量很低，跳过该网站，尝试其他结果
- 认真分析网页中的可交互元素，这是后续生成 query 的关键素材
